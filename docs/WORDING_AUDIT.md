# Wording audit

Reviewed frontend, backend, README and tracked documentation for unsupported operational and predictive claims.

Corrections made:

- Replaced “Live simulated demonstration” with “Simulated telemetry demonstration”.
- Renamed the workflow label to “Simulated replay workflow”.
- Explicitly separated the simulated telemetry demonstration, offline public telemetry research evaluation and planned mission integration.
- Retained “Prototype heuristic indicator” beside risk and health scores.
- Retained human-review, no-command-access and evidence-not-diagnosis boundaries.
- Kept historical Phase 1C references to LSTM only where they state that it is not implemented or justified.

Approved boundary: ASTRA is ground-based decision support using simulated telemetry and offline public-data research evidence. It has no spacecraft command access, requires human review and presents anomaly evidence rather than a confirmed diagnosis. The public benchmark is initial research evidence, not operational validation.
