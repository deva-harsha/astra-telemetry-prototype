# ASTRA Phase 6 report

## Result

Phase 6 adds bounded recorded CSV import, schema mapping, compatibility classification, quality preview, safe replay, provenance-aware JSON export and a printable investigation report.

The existing simulation detector is unchanged. Recorded data reaches it only through the explicit `astra-sim-v1@1.0` profile. Valid files that do not satisfy the profile remain visualisation-only and receive no event, health or risk conclusions.

## Data flow

1. The browser checks the CSV extension, empty-file condition and 10 MB limit.
2. The browser sends raw CSV bytes to the configured ASTRA backend with mapping metadata.
3. The backend enforces the same size limit, a 50,000-row limit, unique headers, valid timestamps and usable numeric telemetry.
4. One reusable backend module calculates preview, quality and compatibility.
5. Compatible data is converted to the existing eight-channel telemetry frame and passed through the unchanged detector and scorer.
6. Visualisation-only data returns timestamped numeric values without detector output.
7. The browser progressively replays the response and keeps operator state in memory.

## Compatibility boundary

The only detector-compatible profile uses all eight existing simulator channels, their documented units, continuous chronological sampling, finite complete values and broad sanity bounds. Unit confirmation is explicit. This is a prototype compatibility contract, not certification.

## Reporting

Event JSON exports include sanitized filename, SHA-256 hash, row count, import time, mapping profile and compatibility status. Full telemetry is excluded.

The print-friendly HTML investigation report contains mission/source context, event evidence, detector state, quality summary, operator review state, generated time and limitations. User-controlled text is HTML escaped.

## Security and privacy

- No permanent file storage
- No database
- No third-party upload
- No filename-derived filesystem path
- No formula execution
- No HTML interpretation of CSV values
- No complete telemetry in report exports
- No complete telemetry logging

## Preserved boundaries

- Detector algorithms and settings unchanged
- Simulator values unchanged
- Risk and health formulas unchanged
- Phase 1C and Phase 4 frozen evidence unchanged
- LSTM remains offline research evidence
- Production remains PyTorch free
- No spacecraft link or command capability

The importer additionally limits files to 64 columns. Compatible analysis requires at least five observations with every timestamp step equal to 60 seconds. The unchanged detector trains on the first 60% of the uploaded file, assumed to represent normal telemetry; ASTRA cannot verify that reference assumption. Uploaded numeric values are preserved in the response. The three-row template demonstrates format and remains visualisation-only until extended to a sufficient recorded sequence.
